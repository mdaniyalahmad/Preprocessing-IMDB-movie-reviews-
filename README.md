# Sentiment-Analysis-IMDB-movie-reviews-

This project demonstrates **text preprocessing** and **sentiment analysis** on the IMDB 50k movie reviews dataset..

---

## **Key Features**

- Text preprocessing: lowercasing, removing non-alphabetic characters, tokenization, stopword removal, lemmatization.
- Feature extraction: TF-IDF vectorization.
- Model: Logistic Regression classifier.
- Displays truncated previews of original and cleaned reviews (100 characters).
